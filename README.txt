كتابي المسموع — نموذج أولي مجاني لتطبيق PWA

النشر:
1. ارفع ملفات هذا المجلد إلى مستودع GitHub عام.
2. من Settings > Pages اختر Deploy from a branch ثم main و /(root).
3. افتح رابط https://USERNAME.github.io/REPOSITORY/ من Safari على الآيفون.
4. اختر مشاركة > إضافة إلى الشاشة الرئيسية.

ملاحظات:
- لا يكفي فتح index.html محليًا للتثبيت؛ يجب تقديمه عبر HTTPS.
- استخراج PDF وDOCX يعتمد على مكتبات من CDN، ويحتاج الإنترنت عند التحميل الأول؛ ملفات PDF المصورة لا تدعم OCR.
- لا يوجد دعم EPUB في هذا الإصدار.
- النطق عبر Web Speech API، وقد لا يستمر في الخلفية أو مع قفل الشاشة على iOS.
- تخزين الكتب في localStorage محدود وقد يحذف iOS البيانات؛ هذه نسخة تجريبية وليست مكتبة حفظ دائمة.
- ملفات الكتب لا تُرفع إلى خادم التطبيق، لكن تحميل مكتبات PDF/Word من CDN يجري عبر الشبكة.
